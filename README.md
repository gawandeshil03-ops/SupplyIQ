# SupplyIQ — Supply Chain Analytics

[Portfolio Home](https://github.com/gawandeshil03-ops) · [Original Repository](https://github.com/gawandeshil03-ops/SupplyIQ)

## Project Overview

This reference project is an end-to-end supply-chain business intelligence solution covering inventory, logistics, suppliers, products, delivery performance, and product segmentation.

## Business Objective

Provide decision-makers with one analytical platform to monitor:

- Revenue and profitability
- Inventory availability and value
- Reorder and overstock conditions
- Logistics cost and delivery performance
- Supplier ratings and lead times
- Return and damage rates
- Product performance and segmentation

## Project Scale

- More than 105,000 shipment records
- 400 products
- 75 suppliers
- 30 warehouses
- Eight Power BI report pages
- 63 analytical SQL queries
- Python-based product clustering

## Technology Stack

- SQL
- Python
- Pandas and NumPy
- scikit-learn
- K-Means clustering
- Power BI
- Power Query
- DAX
- Excel

## Analytical Workflow

```text
Supply-chain datasets
   ↓
SQL database and star schema
   ↓
Power Query transformation
   ↓
Python product segmentation
   ↓
DAX measures and KPIs
   ↓
Interactive Power BI reporting
```
